## 📖 このブログについて

大分トリニータの試合を観戦し、サポーター目線での詳細な分析やレビューを記事にしています。

**コンセプト:**
- 📊 データに基づいた客観的な試合分析
- ⚽ 戦術的な考察と選手評価
- ❤️ サポーターとしての熱い想いを込めた記事
- 📈 シーズンを通じた成長の記録

**対象読者:**
- 大分トリニータのサポーター
- J2リーグに興味がある方
- サッカー戦術分析が好きな方
- 大分トリニータについて知りたい方

## ✍️ 記事の書き方

### 基本ルール

1. **ファイル名の命名規則**
   - 形式: `YYYY-MM-DD-記事タイトル.md`
   - 例: `2025-12-01-season-review-2025.md`

2. **保存場所**
   - すべての記事は `articles/` ディレクトリに保存
   - 画像は `images/` ディレクトリに保存

3. **Frontmatter（必須）**
   ```markdown
   ---
   title: "記事のタイトル"
   date: YYYY-MM-DD
   tags: ["タグ1", "タグ2", "タグ3"]
   ---
   ```

## 📋 記事執筆のガイドライン

### 内容面

✅ **推奨される内容**
- データに基づいた客観的な分析
- 具体的な選手名、時間、プレーの描写
- 戦術的な考察（フォーメーション、プレススタイルなど）
- 建設的な批評と改善提案
- サポーターとしての応援メッセージ

❌ **避けるべき内容**
- 根拠のない批判や誹謗中傷
- 選手・監督への人格攻撃
- 他チームへの侮辱的な表現
- 不確定な情報の拡散

### 文体・スタイル

- **敬体（です・ます調）** を基本とする
- 適度に**データ・数字**を引用する
- **見出し・箇条書き**を活用して読みやすく
- **表組み**でスタッツを整理する
- **太字・斜体**で重要ポイントを強調

### 推奨されるタグ

**チーム関連:**
- `大分トリニータ`, `Jリーグ`, `J2`, `対戦相手名`

**記事種別:**
- `試合結果`, `試合分析`, `シーズンレビュー`, `戦術分析`, `選手評価`

**その他:**
- `ホームゲーム`, `アウェイゲーム`, `重要な試合`, `ダービー`

## 🔧 執筆のヒント

### データ収集

**公式情報源:**
- [J.LEAGUE公式サイト](https://www.jleague.jp/)
- [大分トリニータ公式サイト](https://www.oita-trinita.co.jp/)
- J.LEAGUE公式アプリ

**統計情報:**
- Football LAB
- Sofascore
- Transfermarkt

### 分析の深め方

1. **試合を複数回視聴する**
   - 1回目: 全体の流れを把握
   - 2回目: 特定の選手やポジションに注目
   - 3回目: 戦術的な動きに注目

2. **データと感覚を組み合わせる**
   - 「中盤が劣勢だった」→ スタッツで支配率を確認
   - 「攻めあぐねた」→ シュート数、枠内シュート数を確認

3. **他の試合と比較する**
   - 前節との変化
   - 同じ相手との過去の対戦
   - シーズン平均との比較
